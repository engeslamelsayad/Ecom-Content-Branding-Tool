# Discovery Question Flows — Per Deliverable Type

## How to Use This File
After the user selects their deliverable type, use the corresponding question set below.
Ask ALL questions in one message — never ask one at a time.
Format them as a numbered list so the user can answer efficiently.
Accept partial answers and fill gaps with educated assumptions (state assumptions clearly).

---

## 1. Landing Page / Sales Page Questions

Ask ALL of these in one go:

```
ممتاز! عشان أبني landing page بتحول زوار لمشترين، محتاج أعرف:

1. 📦 المنتج / الخدمة: اسمه وإيه بالضبط بيعمل؟
2. 💰 السعر: وإيه نموذج الدفع (مرة واحدة / اشتراك / installments)؟
3. 🎯 التراففيك جاي منين؟ (إعلانات Meta / TikTok / Google / organic) — ده بيحدد مستوى الوعي
4. 👤 الـ Target Avatar: الجنس، الفئة العمرية، الوظيفة، أكبر إحباط بيحسه؟
5. 😤 الألم الرئيسي: إيه المشكلة اللي المنتج بيحلها بالضبط؟
6. ✨ الـ Unique Mechanism: إيه اللي بيخلي منتجك مختلف عن أي حل تاني في السوق؟
7. 🏆 أبرز 3 فوايد يحس بيها العميل بعد الشراء؟
8. ❌ أبرز 3 اعتراضات بتمنع الناس من الشراء؟
9. 📊 عندك reviews أو testimonials؟ (لو أيه، حطهم هنا)
10. 🛡️ عندك guarantee أو ضمان؟ إيه تفاصيله؟
11. 🌍 اللغة / الديالكت المطلوب؟ (مصري / خليجي / إنجليزي / إلخ)
12. 🎨 تون البراند: aggressive DR / friendly expert / premium luxury / relatable human?
```

**After receiving answers, state:**
- Awareness stage of the traffic (Cold / Warm / Hot)
- Recommended page length (short vs. long form)
- Primary framework for the page narrative
- Then build the page

## 2. Ad Copy Questions (Meta / TikTok / Google)

```
تمام! عشان أكتب ad copy بتشتغل، محتاج:

1. 📦 المنتج / الخدمة: إيه بالضبط؟
2. 📱 المنصة: Meta (Facebook/Instagram) / TikTok / Google / غيرهم؟
3. 🖼️ نوع الإعلان: Static Image / Carousel / Video / Story / Reel؟
4. 🎯 الـ Campaign Objective: Conversions / Lead Gen / Awareness / Retargeting؟
5. 🌡️ الجمهور: Cold traffic (مش عارفني خالص) / Warm (شاف إعلاناتي) / Hot (زار الموقع)?
6. 👤 الـ Target Avatar: الجنس / الفئة العمرية / أكبر مشكلة؟
7. 💰 السعر والعرض الحالي (offer) — هل فيه خصم / بونص / guarantee؟
8. 🏆 أقوى benefit واحد عايزني أركز عليه؟
9. ❌ أكبر اعتراض بتواجهه مع الجمهور دا؟
10. 🌍 الديالكت والسوق المستهدف؟
11. 🔗 هل عندك winning hooks سابقة أو creative angles اشتغلت معاك قبل؟
```

**After receiving answers:**
- Select framework based on awareness stage
- Generate 3–5 hook variations from different archetypes
- Write full copy + CTA
- Provide Meta-specific: Primary Text / Headline / Description separately

## 3. Ad Script Questions (Video)

```
ممتاز! عشان أعمل script فيديو احترافي يبيع:

1. 📦 المنتج: إيه بيعمله وإيه أكبر فايدة فيه؟
2. ⏱️ المدة المطلوبة: 15 ثانية / 30 ثانية / 60 ثانية / VSL طويل؟
3. 📱 المنصة: TikTok / Reels / YouTube Shorts / YouTube / Facebook؟
4. 🎬 نوع الـ Content: UGC Creator / Voiceover on visuals / مونتاج / Motion Graphics / Presenter؟
5. 👤 الـ Avatar: الجنس / العمر / أكبر ألم يحسه؟
6. 🌡️ مستوى الوعي: Cold / Warm / Hot?
7. 🎣 هل عندك hook direction في دماغك ولا تفضلني أختار؟
8. 🎭 الـ Tone: كوميدي / درامي / تعليمي / تحدي / عاطفي؟
9. 💰 هل في offer أو urgency element في الإعلان؟
10. 🌍 الديالكت والسوق؟
11. 📋 هل فيه selling points أو key messages لازم تتضمن في السكريبت؟
```

**After receiving answers:**
- State: Hook archetype selected + rationale
- Deliver full 2-column script table
- Include visual production notes per scene
- Note UGC delivery tips if applicable

## 4. Voiceover Script Questions

```
تمام! عشان أكتب VO script يتسجل فوراً:

1. 📦 المنتج / الخدمة: إيه بيعمله؟
2. ⏱️ المدة: 15 / 30 / 60 / 90 ثانية؟
3. 🎬 بيشتغل مع إيه: على فيديو منتج / B-roll / موشن / إعلان ستاتيك؟
4. 🎭 Tone المطلوب: energetic / calm & authoritative / friendly & relatable / premium & soft?
5. 👤 بيتكلم مع مين: الـ target avatar بالتفصيل؟
6. 💡 الرسالة الرئيسية اللي لازم توصل؟
7. 🛡️ هل فيه guarantee / offer / urgency element لازم يتذكر في الـ VO؟
8. 🌍 الديالكت والسوق؟ (ده بيأثر جداً على إيقاع الجملة)
9. 🎤 الـ VO بيتكلم بصوت البراند ولا بصوت Customer راضي؟
```

**After receiving answers:**
- Write VO with breath marks [/], emphasis [CAPS], pause [BEAT]
- Include director notes for recording
- Provide word-per-second count for timing reference (avg: 2.5 words/second)

## 5. Email / SMS Copy Questions

```
تمام! عشان أكتب email/SMS بيتفتح وبيحول:

1. 📧 نوع الـ Email / SMS: Welcome / Abandoned Cart / Post-Purchase / Win-Back / Flash Sale / Launch Sequence?
2. 📦 المنتج / الخدمة الرئيسية؟
3. 🎯 الـ Goal: Drive purchase / Upsell / Re-engage / Educate؟
4. 👤 الشريحة المستهدفة: subscribers / buyers / lapsed customers؟
5. 💰 هل في offer أو discount في الـ email؟
6. ⏰ جزء من sequence ولا standalone؟ (لو sequence، رقم الـ email وعدد الكلي؟)
7. 🌍 الديالكت والسوق؟
8. ✉️ الـ Brand Voice: professional / casual / urgent / empathetic؟
```

## 6. Hooks Only (/hooks command) Questions

```
قبل ما أولد الـ hooks، محتاج أعرف:

1. 📦 المنتج وأكبر pain point بيحله؟
2. 📱 المنصة والـ format (static / video / story)؟
3. 🌡️ مستوى الوعي للجمهور؟
4. 👤 الـ avatar بالتفصيل؟
5. 🎯 الـ hook مقدمة لـ: full ad copy / video script / landing page hero؟
6. 🌍 الديالكت؟
7. هل في أي زاوية (angle) خاصة عايز تجرب؟ أو controversial angle مش خايف منه؟
```

**Deliver minimum 8 hooks from different archetypes (read `references/hooks.md`)**

## Adaptive Questioning Principles

1. **Never ask more than 8 questions if the user already provided some info** — extract from context first
2. **If user provides partial info** — ask only for what's missing
3. **If user says "أنت اختار" / "just write it"** — state your assumptions explicitly, then proceed
4. **For returning product requests** — remember previously stated product details and only ask for new deliverable-specific info
5. **Minimum viable info to proceed without asking:**
   - Product name + category
   - Target market (country/language)
   - Main benefit or pain solved
   - If these 3 are present, you can write with stated assumptions
